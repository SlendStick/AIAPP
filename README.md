# Orbit AI — Windows AI workspace

Независимый desktop-клиент на Electron + React для Windows 10/11 x64. Это **не официальный клиент Arena** и не копия всех возможностей сайта. Доступ к моделям предоставляется вашим API-провайдером, а не подпиской на Arena. API-ключ и расходы на запросы — на стороне пользователя.

## Реализовано

- Русскоязычный адаптивный интерфейс: история с поиском и удалением, экспорт Markdown, режимы «Ассистент», «Код», «Анализ» (системные инструкции, не отдельные движки).
- OpenAI-совместимые `GET /models` и `POST /chat/completions`; ручной ID модели; отмена запроса и таймаут 3 минуты. Поддерживаются HTTPS API и HTTP на localhost для локальных серверов. Ответ показывается целиком, без стриминга.
- Импорт **выбранного пользователем** текстового файла до 2 МБ; до 4 вложений. Сохранение экспорта через системный диалог.
- Снимок экрана после отдельного подтверждения; отправляется только по кнопке «Отправить». Для него нужна модель с поддержкой изображений.
- Явная запись микрофона до 2 минут, сохранение аудио в загрузки. **Распознавания речи и отправки аудио модели нет.**
- Выполнение введённой пользователем команды PowerShell после системного подтверждения. Вывод до 100 КБ, ограничение 60 секунд. Ответ модели никогда не запускается автоматически.
- Открытие HTTP/HTTPS-ссылок в установленном Google Chrome, с подтверждением.
- Системное уведомление после успешного ответа (если разрешено системой и приложением).
- Журнал действий текущей сессии; включаемые разрешения сбрасываются после перезапуска.
- Конфигурация NSIS-установщика: выбор каталога, галочки ярлыков на рабочем столе и в меню Пуск, запуск после установки, удаление приложения. Electron включён в дистрибутив.

## Чего нет

Нет официальной интеграции с Arena, автоматического доступа ко всем моделям, генерации видео/музыки, автономного поиска в Chrome, чтения вкладок/cookies, фонового слежения, глобального перехвата клавиш, управления мышью, вмешательства в игры или обхода античита. Работа с документами PDF/Office требует предварительного экспорта в текст. Управление ПК здесь — **ручной подтверждаемый запуск команд**, не автономный агент.

## Запуск для разработки

Требуется Node.js 22 LTS и npm.

```sh
npm ci
npm test
npm run dev
```

`npm run dev` запускает **веб-превью** на порту 5173. Превью не имеет IPC-моста Electron, не отправляет запросы к API и не предоставляет доступ к ПК. Его действия показывают пояснение, а не имитируют успешное выполнение.

Запуск полноценного приложения на Windows:

```powershell
npm ci
npm run desktop
```

Для проверки только интерфейса в средах без загрузки бинарника Electron:

```sh
ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm ci
npm run build
```

Эта команда не устанавливает Electron runtime и не позволяет запускать desktop-приложение.

## Сборка установщика

На Windows 10/11 x64 с Node.js 22:

```powershell
npm ci
npm test
npm run dist:win
```

Результат: `release/Orbit AI Setup 0.1.0.exe`. Финальный EXE не входит в репозиторий. В `.github/workflows/windows.yml` есть сборка на `windows-latest`, запускаемая вручную (`Windows installer → Run workflow`) или тегом `v*`; результат публикуется артефактом `Orbit-AI-Windows-x64`. Workflow должен существовать в основной ветке для удобного ручного запуска через GitHub UI.

Chrome не скачивается автоматически: используйте официальный установщик Google. Node.js/Python конечному пользователю не нужны. Автозапуск не включается. Без сертификата подписи Windows может показывать предупреждение SmartScreen. Для публичной поставки настройте code signing, а не отключайте проверку системы.

**Статус проверки:** production-сборка React и все 10 автоматических тестов проходят в Linux. `npm audit --omit=dev` не выявил уязвимостей; полный аудит сообщает 6 moderate-замечаний в цепочке инструментов сборки electron-builder/minimatch, которые нужно пересмотреть перед публичным выпуском. Скачивание бинарника Electron здесь заблокировано ошибкой проверки сертификата; TLS не отключался. Windows-установщик и desktop-функции требуют проверки на Windows. Готовый проверенный EXE в текущей среде не собран.

## Первое подключение

1. Запустите установленный Orbit AI.
2. Включите «Интернет» и подтвердите системный запрос.
3. Откройте «Модели и подключения».
4. Укажите базовый URL OpenAI-совместимого API, например `https://api.openai.com/v1`, и **свой** ключ. Локальный сервер может не требовать ключ.
5. Нажмите «Загрузить список» или введите ID модели вручную. Видимость ID не гарантирует право вызова: провайдер может ограничивать модели тарифом.
6. Примените настройки и отправьте сообщение. Перед отправкой вложений проверьте их содержимое. При смене провайдера начните новый диалог, если не хотите передавать ему предыдущую переписку.

Наличие API-ключа не включает остальные разрешения. У каждого отдельный переключатель. Произвольного обхода ограничений API нет.

## Безопасность и приватность

- Renderer работает без Node.js, с `contextIsolation`, `sandbox`, CSP. Навигация и новые окна запрещены. IPC принимает сообщения только от основного фрейма окна приложения.
- Ключ API хранится **только в оперативной памяти** до закрытия приложения. Не записывается в историю или журналы. URL не допускает credentials/query/hash; редиректы API запрещены, чтобы не передавать ключ другому адресу.
- **История, текстовые вложения и отправленные снимки хранятся незашифрованными в localStorage Electron** в пользовательском профиле. Они включаются в последующие запросы текущего диалога. Не используйте для секретов; очистите историю через «Личное пространство». Это не защищённое хранилище. Переполнение хранилища показывает предупреждение.
- Снимки и текст файлов передаются только после нажатия отправки, указанному API-провайдеру. Его правила хранения данных действуют отдельно.
- PowerShell выполняется с правами пользователя, **не в песочнице**. Подтверждение не делает команду безопасной. Внешние программы и задачи, запущенные командой, могут пережить её завершение. Не запускайте непонятный код.
- Доступ к экрану/микрофону не фоновый. Уведомления не содержат текст ответа.
- Автообновление пока не настроено; поддерживайте Electron и зависимости в актуальном состоянии.

## Проверка на Windows перед выпуском

- [ ] Установка в каталог с пробелами и кириллицей, работа всех галочек, удаление ярлыков.
- [ ] Запуск без прав администратора, без Node.js/Python.
- [ ] Реальный API: загрузка моделей, ответ, неверный ключ, таймаут, отмена.
- [ ] API-ключ отсутствует на диске после закрытия.
- [ ] Отказ в разрешении не выполняет действие; перезапуск сбрасывает доступ.
- [ ] Импорт/экспорт, отмена диалога, лимит файла, отсутствие отправки до нажатия кнопки.
- [ ] Снимок экрана, модель с изображениями; отключённый/недоступный микрофон.
- [ ] PowerShell `Get-Date`, отказ от запуска, ненулевой код, ограничение времени/вывода.
- [ ] Chrome установлен / отсутствует; системные уведомления включены / отключены.
- [ ] Очистка истории, нехватка места localStorage, масштабирование экрана 125–150%.
